# BLOW YOUR PHASE OFF

A monophonic FM **drone** instrument. Brutal, in the best possible way.

The mathematics is Fibonacci — the entire patch architecture is generated by
the recursion `F(n) = F(n-1) + F(n-2)` — but the personality is phase
violence: golden-ratio inharmonicity, operators that haunt reverb rooms they
don't belong in, and a drone that phase-modulates itself with its own
inverted past. (The name arrived by mistype on 2026-08-03 and was
immediately correct. The engine workspace keeps the working name
`fibonacci-synth`, same as Séance lives in `unicode-daw`.)

Written in Rust as a deliberate trial of Rust over C++ for audio work.

No envelopes. The instrument sounds until you tell it not to. Expression comes
from restructuring the algorithm live, switching operators on and off (true
resets, not bypasses), pitch glide, and the INDEX / rip / haunt controls.

```
cargo test                             # engine + structure tests
cargo run --release --example render   # audition WAVs -> renders/
```

## The mathematical models

Everything the engine does that isn't plain FM synthesis is listed here. If a
number in the instrument feels arbitrary, this section should explain it; if
it doesn't, that's a documentation bug.

### 1. Structure: the Fibonacci recursion tree

An algorithm is defined recursively, mirroring `F(n) = F(n-1) + F(n-2)`:

- `F(1)` and `F(2)` are a single sine operator.
- `F(n)` combines an `F(n-1)` cluster with an `F(n-2)` cluster.

`F(5)` gives exactly **5 operators** and **4 combination nodes**. Each node
makes one binary choice:

- **Series** — the larger sub-cluster phase-modulates the smaller one's
  *primary carrier* (all of the larger side's carriers aim at that single
  operator). Output then comes only from the smaller side.
- **Parallel** — both sub-clusters stay carriers and are summed.

The four choices form a 4-bit algorithm ID, so the generative space has 16
points. Because the Fibonacci tree is asymmetric (`F(4)` vs `F(3)` under the
root), every algorithm is a lopsided tree — unlike the tidy symmetric charts
on classic FM synths. The trees never exceed modulation depth 4: a Series root
aims the deep `F(4)` chain at the *carrier* of the other side, producing a
branch, not a longer stack. The asymmetry is the character.

Operator numbering is left-deep preorder, which has a useful consequence:
**operator 1 (index 0) is the deepest leaf in every algorithm**, so
self-feedback always lives there (§5).

### 2. The shipped algorithms: 5, because 5 is Fibonacci

The number of algorithms the instrument exposes is itself a Fibonacci number,
starting at 5. The five shipped IDs are the **unfolding sequence** — starting
fully Series and flipping exactly *one* tree node to Parallel per step:

| # | ID (bits) | Structure | Carriers | Max depth |
|---|-----------|-----------|----------|-----------|
| I   | `0000` | full FM tree: `(1→2→3)` and `4` both modulate `5` | 1 | 4 |
| II  | `1000` | true 4-op stack `1→2→3→4`, plus sine `5` | 2 | 4 |
| III | `1001` | 3-op stack `1→2→3`, plus sines `4`, `5` | 3 | 3 |
| IV  | `1011` | FM pair `1→2`, plus sines `3`, `4`, `5` | 4 | 2 |
| V   | `1111` | five parallel sines (pure additive) | 5 | 1 |

Carrier count runs 1, 2, 3, 4, 5; modulation depth falls 4, 4, 3, 2, 1. The
instrument unfolds from one deep FM tree into an additive bank, one toggle at
a time. (Bit order in the ID is node preorder: root `F(5)`, `F(4)`, deep
`F(3)`, root-side `F(3)`; set bit = Parallel.)

Growing the roster later means curating more IDs out of the same 16-point
space at the next Fibonacci numbers: 8, then 13.

### 3. Ratio modes: five models for operator frequencies

Each operator's frequency is the voice's base frequency × its ratio × its
detune. A patch's ratio mode fills in the default ratio table (per-operator
override always possible). The roster holds a **Fibonacci number of modes
(5)** — the same rule the algorithm roster follows.

**Golden is the identity mode and the default.** The instrument's sound *is*
the maximally-inharmonic φ territory; Harmonic and Fibonacci are kept as the
consonant reference points you leave from, and GoldenMirror/Plastic are
deeper cuts of the same madness.

| Mode | Ratios (op 1..5) | Model |
|------|------------------|-------|
| **Harmonic** | 1, 2, 3, 4, 5 | The integer harmonic series — the consonant reference point. |
| **Fibonacci** | 1, 1, 2, 3, 5 | The Fibonacci numbers themselves. A subset of the harmonic series, so still consonant — but ops 1 and 2 sit at *unison*, which is where per-op detune becomes thickness/beating. |
| **Golden** *(default)* | 1, φ, φ², φ³, φ⁴ | Powers of the golden ratio φ = (1+√5)/2 ≈ 1.618. φ is the "most irrational" number — its continued fraction is all 1s, so it is the number *worst* approximated by any fraction. Partials at φ-powers are therefore maximally far from every harmonic relationship: maximally inharmonic. Bell-like, metallic, industrial. |
| **GoldenMirror** | 1/φ², 1/φ, 1, φ, φ² | The same φ-powers, mirrored around the fundamental (exponents −2…+2). Identical inharmonicity, but two partials sit *below* the base pitch — and since operator 1 is both the lowest partial and the deepest modulator/feedback home (§1, §5), deep algorithms get slow, heaving modulation from underneath. The subterranean variant. |
| **Plastic** | 1, ρ, ρ², ρ³, ρ⁴ | Powers of the plastic number ρ ≈ 1.3247, the real root of **x³ = x + 1** and the limit of consecutive *Padovan*-sequence ratios (`P(n) = P(n-2) + P(n-3)` — the Fibonacci recursion's nearest cousin). Inharmonic like φ, but the partials pack far tighter (top partial ≈ 3.1× the fundamental instead of ≈ 6.9×): dense, dark, clustered. |

The Golden mode is the thematic punchline: φ is the limit of ratios of
consecutive Fibonacci numbers, so the Fibonacci and Golden modes are the same
idea viewed from opposite ends — one converging on consonance, the other on
its exact complement. Plastic tells the same story one recursion over, via
Padovan.

### 4. Default levels: golden decay `1/φ^(depth−1)`, run hot

When a patch is initialized, carriers get level 1.0 and every modulator gets
`1/φ^(depth−1)` (depth 2 → 0.618, depth 3 → 0.382, depth 4 → 0.236), with
default feedback 0.5. Modulation index still shrinks geometrically with
depth — the golden decay keeps deep stacks bounded — but the exponent is one
φ-power hotter than the conservative `1/φ^depth`, and that is deliberate:
both variants were auditioned and the hot one **is** the instrument. The
stock patches start at the intended energy, not at a polite version of it.

(Conversion to actual FM index: a modulator at level 1.0 swings its target's
phase by 2π radians; see `MOD_SCALE` in `voice.rs`.)

### 5. Feedback: the deepest leaf

Self-feedback is assigned to the deepest operator of the current algorithm
(lowest index on ties) — which, by the tree's numbering, is **always operator
1**. Feedback modulation uses the average of the operator's previous two
output samples (the standard two-sample-average trick that keeps high
feedback from flipping into broadband chaos), scaled to π radians at
feedback = 1.0.

### 6. Drone semantics: the off switch is a reset

There are **no envelopes** anywhere in the engine.

- The voice drones at its current pitch indefinitely. Pitch changes glide
  (one-pole smoothing, patch-settable time, 0 = instant).
- Each operator has a **power switch**. Off = fade out over ~2 ms (de-click),
  then the phase accumulator — and feedback history, if it's the feedback
  operator — is **zeroed**. An off operator holds no ghost state.
- Turning an operator on starts it from phase 0, every time. A re-enabled
  operator is bit-identical to a freshly created one (this is tested).
- Switching algorithms recompiles the routing and re-strikes all operators
  from phase 0 — a deterministic restructure, deliberately not a crossfade.

Determinism is a design goal throughout: the same control sequence produces
bit-identical audio regardless of render chunk size.

### 7. Mix normalization

The output is the *mean* of the carrier outputs (× master level), using the
algorithm's compiled carrier count. Switching a carrier off makes the drone
quieter rather than silently renormalizing the others — no level pumping when
you sculpt the structure.

### 8. The INDEX macro: golden-exponent depth curves

One knob, 0..1, that scales every modulation source — but each operator
follows its own nonlinearity, shaped by its depth in the tree:

> response(depth, x) = x^(φ^(depth−2))

| depth | exponent | curve |
|-------|----------|-------|
| 2 | φ⁰ = 1 | linear |
| 3 | φ ≈ 1.618 | convex |
| 4 | φ² ≈ 2.618 | more convex |
| 1 (carrier self-feedback, algorithm V) | 1/φ ≈ 0.618 | concave — feedback grit arrives *first* |

Every curve hits exactly 0 at index 0 and exactly 1 at index 1, so index 0
is pure sine carriers (the feedback path scales through the same family, so
it also goes silent) and index 1 is the stock sound. Deeper operators lag
further behind at mid-knob, so raising INDEX blooms the tree from the
shallow modulators downward: **the INDEX knob unfolds the tree in time**, the
same gesture as the algorithm sequence but continuous. Carrier output levels
are untouched — this is a modulation-depth control, not a volume knob.

### 9. The Room: a comb constellation built from the tone's own ratios

A stereo reverb (`reverb.rs`) that doesn't reverberate the mix — it listens
to the operators *individually*. Every operator feeds its own pair of comb
filters, one per ear:

- **Left-ear delays come from the operator's frequency ratio**:
  `29 ms / √ratio`. The room inherits the patch's consonance model: in
  Golden mode the ten comb delays are φ-spaced — mutually irrational, modes
  maximally non-coincident, the smoothest possible tail (the same
  continued-fraction argument as §3, now in the time domain) — while in
  Harmonic mode the delays are rationally related and the room turns tuned
  and resonant. The reverb character is *derived from*, not added to, the
  patch.
- **Right-ear delays are the golden midpoints of the left**: `left × √φ`.
  Each right comb sits exactly halfway (geometrically) up the left ladder,
  so the two ears share no delay and their tails decorrelate — that is the
  entire stereo image; there is no panning anywhere.
- **Ghost sends**: modulators are inaudible in the dry mix (they only bend
  phase), but the Room hears them at `ghost × 1/φ^(depth−1)`. The hidden
  interior of the tree is audible only in the reverb — the room is haunted
  by operators that don't exist in the direct sound.
- **Diffusion**: two series allpasses per ear (5.1 ms and 5.1/φ ms) with
  coefficient 1/φ = φ − 1 ≈ 0.618.
- **Decay**: per-comb feedback follows the RT60 model `g = 0.001^(T/rt60)`,
  with a one-pole lowpass in each loop (`damp`) for high-frequency rolloff.
- On an algorithm/mode change the delay *taps* move but the buffers keep
  their contents: the previous structure's tail briefly haunts the new one.

Parameters: `mix` (wet/dry), `ghost`, `rt60` (seconds), `damp`, `haunt` (§10).

### 10. The Ghost Line: phase-inverting cross-feed echoes

`haunt` (0..1, default 0 — fully off leaves the Room bit-identical) adds a
recirculating delay per operator with two twists:

- **The echo comes back in the wrong room.** Ghost Line *i* is fed by
  operator *i* but injects into operator *(i + 3) mod 5*'s combs. 3 is a
  Fibonacci number coprime with 5, so the cross-feed is a single 5-cycle:
  ghost energy visits every operator's combs before arriving back home.
- **Every pass rotates its phase.** The recirculation path runs through a
  first-order allpass whose coefficient is solved (numerically, at startup)
  so the design pitch — 110 Hz, A2, the instrument's home drone — is rotated
  by exactly **π/5 per pass**: after F(5) = 5 passes the echo is fully
  *inverted* against the drone that spawned it; after 10 it is back in
  phase. Because the drone never stops sounding, this drift is audible as
  slow, breathing cancellation and reinforcement — movement no envelope is
  making. Higher partials rotate at their own (frequency-dependent) rates
  and smear apart from the fundamental as the passes accumulate.

Each line's delay is the golden interval above its source's left comb
(`φ × T_left`), and the loop gain is `0.92 × haunt`, always < 1 — the ghosts
fade slowly (aggressively, but they do fade); they don't take over.

### 11. The Rip: the drone phase-modulated by its own inverted past

`rip` (0..1 on the *patch* — this one is synthesis, not effect; default 0 =
off, bit-identical to no Rip Line existing) transplants the Ghost Line's
mechanism inside the voice and closes the loop through the oscillators
themselves:

- The carriers' mean output feeds a delay line at the golden interval
  (φ × 29 ms), recirculating (loop gain `0.9 × rip`) through the same
  π/5-per-pass phase-rotating allpass as §10.
- The line's output is injected into **every carrier's phase input**
  (π radians at rip = 1) — not into the mix. Because this is a
  phase-modulation synth, the delayed copy *interferes with the modulation
  already shaping the carrier*: as its rotation accumulates toward
  inversion, it partially cancels the live modulation structure, and the
  spectrum hollows out; as it rotates past, the modulation blooms back.
- The result is a cyclic spectral wobble with no LFO anywhere — the wobble
  *is* the interference pattern between the drone and its own rotated past,
  and different partials rip at different rates because the allpass rotation
  is frequency-dependent.
- Two safeties keep the worble liquid instead of noisy (added after
  audition — unbounded recirculation could build ~10× amplitude and push
  the carriers into the chaotic-PM regime, the same papery hiss as
  over-driven operator feedback): the injection passes through an algebraic
  soft limiter `x/(1+|x|)` so the phase swing is *capped* at π radians no
  matter how hot the loop runs, and the recirculation is damped by a
  one-pole lowpass at coefficient 1/φ² — the past darkens as it decays, so
  highs never stack into hiss.

The Rip participates in the determinism contract: it is cleared on every
algorithm restructure and covered by the chunk-invariance tests.

## Architecture

```
fibonacci-synth/
└── crates/
    ├── fibonacci-dsp/      pure DSP, no dependencies, allocation-free audio path
    │   ├── src/algorithm.rs   the tree space + compiler (ID -> flat routing)
    │   ├── src/patch.rs       ratio modes, INDEX curves, golden-decay defaults
    │   ├── src/voice.rs       the mono drone voice (Frame output for the Room)
    │   ├── src/reverb.rs      The Room: per-op stereo comb constellation
    │   ├── tests/engine.rs    determinism / reset-contract / numeric health
    │   └── examples/render.rs offline WAV audition renders
    ├── fibonacci-app/      realtime shell: cpal (WASAPI) stereo out, midir in, REPL
    └── fibonacci-gui/      the 1-bit front end (egui): binary blow-your-phase-off-gui
```

Algorithms are compiled at patch-change time into per-operator modulator
bitmasks plus a deepest-first evaluation order; the audio loop is a linear
pass over 5 operators per sample. No tree-walking, no allocation, no locks on
the audio thread. In the app, the audio callback owns the voice; the REPL and
the MIDI thread each feed it through their own SPSC lock-free ring of `Copy`
events.

Run the instrument (it drones immediately — no play button):

```
cargo run --release -p fibonacci-app
```

The binary is named `blow-your-phase-off.exe`.

### 12. The melodic engine: a golden sample-and-hold

A deterministic S&H pitch source (`melody.rs`) that drives the voice's
existing glide — `glide_seconds` is the legato control. Parameters: rate
(Hz), range, root, tuning, scale, and hold source.

**Hold sources** (both deterministic — same settings, same melody, forever):
the **golden Weyl sequence** `x ← (x + 1/φ) mod 1`, an irrational rotation
that is provably equidistributed and never repeats; or a fixed-seed
xorshift32 for noise-flavored (still reproducible) picks.

**Tunings — 5, a Fibonacci number**:

| Tuning | Model |
|--------|-------|
| **scale** | Quantized to 12-TET via the 8-scale roster below. |
| **fib hz** | The Fibonacci numbers as raw frequencies: 34, 55, 89, 144, 233, 377, 610, 987, 1597, 2584 Hz. Absolute (root is ignored). 55 Hz is A1; consecutive rungs converge on φ — 987/610 = 1.61803. |
| **phi powers** | `root · φᵏ` — the melody walks the same maximally-inharmonic series the Golden ratio mode tunes the operators to. |
| **rho powers** | `root · ρᵏ` — steps of log₂(ρ)·1200 ≈ 486 cents, a not-quite-half-octave belonging to no temperament. |
| **phi walk** | Each fire multiplies the current pitch by φ or 1/φ, geometrically reflected off the range bounds (a mirror in log-frequency). No grid exists; every interval is golden. Ranges under ≈833 cents pin the walk to its bounds. |

**Scales — 8, Fibonacci again**: phrygian, phrygian dominant, natural
minor, harmonic minor, neapolitan minor, byzantine (double harmonic), plus
two derived:

- **fibonacci** `[0,1,2,3,5,8]` — the degrees are the Fibonacci numbers
  mod 12, and the scale terminates itself: the next number, 13, is
  octave-equivalent to 1, already present.
- **phyllotaxis** `[0,1,3,6,7,8,10]` — 7 notes placed around the pitch
  circle at the golden angle (steps of 12/φ ≈ 7.416 semitones, rounded),
  the way a sunflower places seeds. The result is **Phrygian with its 4th
  sharpened to the tritone** — six of Phrygian's seven notes are golden.
  The hunch that Phrygian is φ-flavored is checkable, and checks out
  (verified in `melody.rs` tests).

## The front end (milestone 3)

```
cargo run --release -p fibonacci-gui
```

Strict 1-bit (white on black, hard rectangles, monospace), with dithering
standing in for brightness everywhere — an operator's live output level is
rendered as stipple density. Panels:

- **The Monolith** (centerpiece): a golden logarithmic spiral whose
  vertices are displaced by the live stereo side signal (L−R) and whose
  segments crack out as rip + haunt rise. Coherent phase leaves the shell
  serene; phase violence visibly breaks it.
- **The tree**: the recursion structure, S/P glyphs per node, leaves
  stippled by live level. The blinking node is the one that flips to reach
  the neighbouring roster algorithm — clicking it moves along the
  unfolding. Other nodes are dormant until the roster grows to 8.
- **The Room**: the cross-feed graph drawn as what it mathematically is — 5
  operators on a circle with rotation-by-3 arcs, i.e. a pentagram. Solid
  when haunt > 0, dotted when dormant.
- **LOCAL φ INTEGRITY**: a display composite, `100·(1−max(rip, haunt))` —
  the formula is printed next to the meter.
- **Scopes**: mono waveform, plus an L/R Lissajous (mid/side rotated) —
  the phase image itself.
- **Event log**: timestamps + measurements only. Every line the program
  authors must be verifiable against the engine or against mathematics;
  anything else is a bug.
- **The voice** (`crates/fibonacci-gui/assets/voice.txt`): all *voiced*
  text is data, not code — one text box per blank-line-separated paragraph,
  `#`-paragraphs ignored, hot-reloaded every ~2 s while running. The file
  ships empty; its author is Billy.
